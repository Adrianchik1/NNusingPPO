Example of a structure of a Neural Network using Proximal Policy Optimization.
Programmed using a guide from https://youtu.be/Wo5dMEP_BbI?si=ohs4ktQBqep1QmF0.

Python version: 3.9.6
NumPy version: 2.0.2
Matplotlib version: 3.9.4

You can adjust both the number of iterations and the magnitude by which the weights and biases are updated in each iteration.
At the end of the program, it will display two graphs: the first shows the overall change in loss per iteration, while the second illustrates how the loss varies with each iteration.
